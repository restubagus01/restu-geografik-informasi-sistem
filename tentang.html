Tentang Aplikasi

Web Peta Desa merupakan sistem informasi geografis berbasis web yang digunakan untuk menampilkan informasi wilayah desa dan kecamatan secara interaktif. Aplikasi ini bertujuan untuk memudahkan pengguna dalam mengakses peta wilayah, data penduduk, fasilitas umum, serta informasi administratif lainnya.

Fungsi Utama

  • Menampilkan peta kecamatan dan desa
  • Menyajikan data penduduk
  • Menampilkan fasilitas umum
  • Menyediakan informasi wilayah

Teknologi

  • HTML, CSS, JavaScript
  • QGIS & Web GIS
  • Leaflet / OpenStreetMap
